# 📱 Offline Expense Tracker

An offline expense tracker app to manage daily, weekly, and monthly expenses.

## 🚀 Features
- Track expenses (daily, weekly, monthly)
- Spend analysis with pie charts
- Date filter for better insights
- Add new expense with date, amount, notes, and category
- Works completely offline

## 📊 Screens
- Expenses
- Spend Analysis
- Add New Expense

## 🛠️ Tech
- Kotlin and JetPack Compose
